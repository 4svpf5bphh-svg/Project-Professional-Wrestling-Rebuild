# Legends artwork delivery — approved 131-unlock catalogue

**Release rule:** The current 48 collectible card assets and 49 roster portraits are already present in `apps/web/public/assets/legends/`. There are **83 additional approved unlocks**: **72 single-wrestler cards** and **11 team cards** containing **23 individual wrestlers**. Once complete, the collection will have **131 cards and 144 individual wrestler portrait mappings**.

**What to provide:** 106 ideally named source images in the accompanying [CSV checklist](legend-photo-checklist.csv): one photograph for each of the 72 singles, one group photograph for each of the 11 teams, plus a member-specific original for each of the 23 team members. A crisp, crop-friendly team photo can substitute for an individual source once the faces have been manually verified, as we did with the Road Warriors. High-quality JPEG/PNG/WebP is fine; naming is suggested, not mandatory. The catalogue `src/domain/approved-legend-expansion.ts` is authoritative if captions or aliases differ.

**Preferred hand-off:** Submit the photos in an archive or manageable batches, keeping each image tied to a wrestler name; no new images should be guessed or silently substituted. User-submitted photo sources are staged separately from production assets. If direct ChatGPT attachments cannot reliably transfer all binary bytes into GitHub, use the owner’s explicit GitHub development branch upload workflow rather than claiming that a local ZIP alone will deploy. GitHub **binary blob creation has been tested**, so commit final WebP images using blob SHA + tree + commit on the approved development branch. Do not use the UTF-8-only create-file action for images.

**Processing plan:** Validate the image subject and any labels, inspect face/crop framing, retain original-source provenance, render a **single tier-specific WebP card** as the reveal/Vault/album/full-card image, and render **480 × 624 WebP** roster/market portraits from the same source or the separate member original. Team cards have one shared group reveal, but each wrestler receives an individual mapped portrait. Store image assets under `apps/web/public/assets/legends/`, update `src/ui/legend-portrait-assets.ts`, and add full curated `src/domain/legends-catalogue.ts` entries with prime-era style, moves, thresholds, clue, unlock metric, market status and member identities.

**Quality gates:** Never activate a Legend with missing or misidentified artwork. Verify every photo filename, dimensions, portrait registry ID, reveal/card link, rarity badge position, team member order, alt text, responsive layout, and gallery ownership; verify the same artwork appears in the unlock reveal and collected card album. Full PostgreSQL and browser regression must pass, then rehearse the complete image-integrated release on a cloned World before a single approved Production deployment.

**Historic image adjustments:** Prior user feedback requested replacing/reviewing Animal, Último Dragón, Kenta Kobashi, Abdullah the Butcher, Mitsuharu Misawa and Bruno Sammartino, plus keeping tier badges above nameplates and preserving the Road Warriors shared team-card photo. Confirm those image/crop replacements are in the final asset batch if still unsatisfactory.

**Do not:** generate fake faces, repeat The Young Bucks as Legends (both already exist in the live roster), introduce a second World deadline, deploy from the feature branch, create unnecessary image-preview deployments, or assume a photograph is commercially licensed just because it was supplied.
