# Rebuild Creative Mandate

The user grants broad creative discretion for the new PPW application when its design stage arrives. Use that discretion to propose and implement a coherent, original, mobile-first experience rather than copying the old UI screen-for-screen.

Creative freedom is **not** permission to change the agreed multiplayer simulation rules, delete archived data, deploy prematurely, introduce pay-to-win mechanics, or bypass review for high-impact changes.

Design principles:
- A strong, recognizable PPW identity with distinctive navigation, typography, colour and motion, while remaining readable and accessible.
- Messenger-style Backstage, where conversations and choices feel alive and persistent.
- Results as a headline feature: wrestling-fluent narrative, exciting match/segment presentation, consequences, visual highlights, and optional detail.
- A concise mobile interface with deep simulation behind it: TEW underneath, EWR on top.
- Prefer creative decisions that improve clarity, personality and delight without inflating database payloads or sacrificing deterministic, server-authoritative outcomes.
- Player-authored finishes and scripted segment outcomes remain authoritative.
- Apply the four questions before major features: dependencies in/out, simulation versus presentation, and smallest complete version.

See docs/PRESENTATION-DIRECTION.md for detailed requirements.
